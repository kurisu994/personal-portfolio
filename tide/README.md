# 潮汐 · TIDELINE（简易版）

单文件实现，零第三方依赖，不发起任何网络请求。用浏览器直接打开 `index.html` 即可运行。

```sh
open index.html
```

工程版（React + Three.js + Rsbuild）在相邻的 [`../tide-showcase/`](../tide-showcase/)。设计稿见 [`../docs/specs/tide.md`](../docs/specs/tide.md)。

## 这是什么

一段潮间带的测绘图：上半是剖面 A—A，下半是同一横向比例的平面。潮水按真实的月相与谐波模型涨落，剖面里的水位、涌浪和上冲水膜随之变化；平面里能看到湿沙带、泡沫花边和一道道向岸推进的波峰线。在平面上写下的字，涨潮时会被一点点收回。

不带参数打开时，时间取此刻；带参数的链接会还原到指定的海岸与当地时刻，格式与工程版相同：

```
index.html?coast=beach&date=2026-09-30&time=14:30
```

`coast` 取 `beach`（细沙滩）、`estuary`（河口泥滩）或 `inlet`（内海）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 海岸 | 左上角切换三种海岸；换海岸时保持当地钟面时间 |
| 日期 / 潮汐表 | 改日期，或在右上角潮汐表上拖动（聚焦后用方向键，按住 Shift 一次走一小时） |
| 时间流速 | 1:200 / 1:600 / 1:3000；空格暂停。暂停只停潮汐钟，浪照常拍岸 |
| 手写 | 在平面里拖动，沙上留下划痕 |
| 写字 | 输入文字（最多 12 个字），再点一下平面里的沙滩；指针移到平面上时会预览落字的位置与大小 |
| 抹平 | 清除沙上所有痕迹 |
| 剖切位置 | 拖动平面左缘的「A」，或聚焦后按上下方向键，剖面随之移到沿岸的另一处 |
| 声音 | 首次点击才创建音频：涌浪、底层涌声、泡沫破裂三层，全部程序化合成 |
| 分享 | 复制带海岸、日期与时刻的链接；暂停时地址栏会自动写入当前时刻 |

## 与工程版的差异

| | 简易版（本目录） | 工程版 |
| --- | --- | --- |
| 依赖 | 无 | React · TypeScript · Three.js · lucide |
| 视角 | 剖面加平面，两张正投影图 | 三维镜头（漫步、蹲守、自由） |
| 湿度 / 痕迹 / 泡沫场 | CPU 上的 `Float32Array`，每帧整张推进 | GPU 半浮点乒乓渲染目标 |
| 书写 | 在平面上直接落笔 | 三维射线与地形求交 |
| 天空 | 日月正投影到剖面所在的竖直面，画出当天的日月弧 | 天空球、星空与月相圆盘 |

两版共用的部分：潮汐模型、三种海岸预设、地形生成函数、上冲公式、湿度与痕迹的生命周期规则、音景的三层结构和十二段诗。

## 两版同源

`index.html` 里 `// MODEL:BEGIN` 与 `// MODEL:END` 两行之间是从工程版 `src/tide/model.ts`、`src/tide/lifecycle.ts` 和 `src/data/coasts.ts` 逐行移植的模型段。工程版的 `pnpm verify:tide` 会把这一段原样取出，放进独立的 Node `vm` 上下文执行，与工程版逐项对账：

- 海岸与分潮表、周期表、生命周期常数逐字段一致；
- 三种海岸 30 天逐小时潮位，各自用自己的数据计算，差值小于 1e-9 米；
- 三天内的高低潮时刻差小于 1 秒，月相与大小潮判定逐小时一致。

改动模型时两边要一起改，否则这一项会失败。地形函数与上冲公式同样是逐行移植（分别来自 `src/scene/terrain.ts` 与 `src/scene/shaders.ts`），它们只影响画面，不在对账范围内。

## 几个实现上的取舍

**剖面加平面，而不是只画剖面。** 设计稿原定只画侧视剖面，但侧视看不见沙面，写字无处落笔。于是借用测绘图的格式：剖面负责「潮位涨落」，平面负责「写字被抹去」，两张图横向比例相同、上下对齐，水边线可以直接投影下来。剖面里的湿沙表皮与泡沫读的正是平面那张场在剖切线上的一行，两张图不会各说各话。

**剖面纵向放大。** 二百米宽的画面里，三米多的潮差只有一指宽，所以剖面纵向放大 3–7 倍，倍数标在剖面左下角。平面不做放大，比例尺按屏幕宽度取整。

**场的分辨率跟着视口走。** 建场时按屏幕宽度取 400–840 列，格子数封顶 24 万；跨过窄屏与宽屏的分界才重建。只有水边一带的格子需要算上冲，其余格子只做乘法衰减。1440 × 900 下每帧脚本约 5 毫秒；持续掉帧时降到 1 倍像素密度。

**字按两倍分辨率排版。** 文字先在离屏画布上按两倍格子分辨率排版，再 2 × 2 平均写进痕迹场，笔画边缘才不发毛。痕迹的浮雕效果来自场的对角差分：迎光的一壁亮、背光的一壁暗，沟底略深。

**窄屏只看潮间带。** 窄屏换一套更紧的取景；窄且矮的屏幕收起潮汐表，只留读数。

**界面色调两态切换。** 与工程版相同：按天光带回差在「纸色墨字」与「底片黑银白字」之间切换，用 1.2 秒过渡，避免黄昏时墨色与底色一起落到中灰。

## 调试接口

`window.__TIDE__` 暴露 `snapshot()`、`setTime(jd)`、`setPlaying(on)`、`setSpeed(speed)`、`setCut(z)`、`writeText(text, x, z)`、`shoreline(z)`、`fieldAt(x, z, r)` 与 `view()`，供工程版的 `pnpm verify:simple` 使用。页面自身的逻辑不读它。

## 验收

验收脚本放在工程版目录，复用那里的 Playwright 与模型代码：

```sh
cd ../tide-showcase
pnpm install --frozen-lockfile
pnpm verify:tide     # 纯 Node，其中「零依赖版同源」一项对账本文件的模型段
pnpm verify:simple   # 真实浏览器：三种海岸 × 四个潮位阶段、界面书写、写字 → 涨潮 → 抹去、零网络请求、窄屏
```

`verify:simple` 自己起一个只服务本文件的临时服务器，不需要先启动 dev；截图与报告写到 `../tide-showcase/artifacts/simple/`（已忽略）。
