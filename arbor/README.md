# 一木 · ARBOR · 简易版

> 不催一叶，不问归期。

原《树之物语 · SHUZHI》的零依赖单文件版，目录由 `shuzhi/` 更名为 `arbor/`。直接打开 `index.html` 即可运行，不加载第三方库、字体、图片或音频。

- 点击「落子生根」进入。
- 向下滚动看树生根、展叶与结果，向上滚动回到种子。
- 鼠标移动不再改变树形或带动画面，保留轻微自然风摆。
- 顶部按钮切换声音与全屏。

工程版见相邻的 [`../arbor-showcase/`](../arbor-showcase/)，使用 TypeScript、React、Three.js 与 GSAP 构建真实三维树景。

名称、开场与五章诗句已同步更新为「藏春、初见、向远、听风、归一」。原 Canvas 生长与绘制结构保留。

静态部署路径为 `/arbor/`。旧 `/shuzhi/` 地址未设置自动重定向；如已对外发布，可在自己的静态服务器配置中增加重定向。
