# 候鸟 · MIGRATION · 简易版

一群折纸候鸟沿着河流飞过田野、雾、暮色、雪与星夜，穿越五种气候，没有终点。这个目录是零依赖的单文件实现：整个作品就是一份 `index.html`。

工程化实现见相邻的 [`../migration-showcase/`](../migration-showcase/)。

## 本地运行

不需要构建，也不需要安装任何东西，直接打开即可：

```sh
open index.html
```

整份文件不发起任何网络请求——画面、字体、图标和配乐全部内嵌，断网也能完整运行。也可以把它放到任意静态服务器上。

## 操作

开场选择起飞气候，点击「开始迁徙」。暖纸、雾境、暮粉、雪境、夜航五种气候决定航线的起点与色调。

- **移动指针**引风，鸟群顺着风偏转；指针停下，风也慢慢散去。
- **拖动**在自主镜头下旋转视角，**滚轮**缩放。点「自动运镜」把镜头交还给导演系统。
- 顶部按钮分别切换诗句、声音、镜头、全屏与暂停。

| 快捷键 | 作用 |
| --- | --- |
| `空格` | 暂停 / 继续 |
| `M` | 开启 / 关闭声音 |
| `C` | 切换自动 / 自主镜头 |
| `F` | 切换全屏 |
| `P` | 显示 / 隐藏诗句 |

## 实现

单文件 622,069 字节，零第三方依赖：

- 全部画面由 **Canvas 2D** 手写，没有 WebGL，也没有渲染库。
- 地形按分块生成，沿途持续创建新分块；每次起飞使用随机种子，所以没有两段完全相同的航线。
- 配乐以 **Base64 内嵌**，用 WebAudio 播放，不加载任何外部音频文件。
- 13 段中英短诗随航线轮换，桌面 30 只鸟、触屏 22 只，全部共用同一套手绘几何。

## 部署

由根目录的 [`deploy.sh`](../deploy.sh) 统一发布到 `/migration/`。仓库内的两件作品共用一个 nginx 容器，架构与细节见 [`deploy/README.md`](../deploy/README.md)。

单独使用也可以：把 `index.html` 放到任意静态服务器的目录下，访问时保留结尾的 `/`。
