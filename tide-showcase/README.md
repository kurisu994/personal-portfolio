# 潮汐 · TIDELINE（工程版）

一片潮间带，潮水按真实的月相与谐波模型涨落。可以在沙上写字、画线，涨潮会把它们一点点收回去。

设计稿见 [`../docs/specs/tide.md`](../docs/specs/tide.md)。零依赖版在相邻的 [`../tide/`](../tide/)：一张剖面加平面的测绘图，模型段逐行移植自本版，`pnpm verify:tide` 会把两份模型逐小时对账。

---

## 本地运行

使用 Node.js 22.12+ 和 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:3000/`。不带参数打开是开场页，时间取此刻；带参数的链接会跳过开场，直接到水边：

```
?coast=beach&date=2026-09-30&time=14:30
```

`coast` 取 `beach`（细沙滩）、`estuary`（河口泥滩）、`inlet`（内海）；`date` 与 `time` 是该海岸的当地时间。暂停时地址栏会自动写入当前时刻，分享按钮复制的也是这条链接。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 海岸 | 三种预设：半日潮为主的开阔沙滩、潮差大且涨快落慢的河口泥滩、日潮不等明显的礁岸内海 |
| 日期 | 大潮小潮跟着真实月相走：朔望前后潮差最大，上下弦最小 |
| 时间流速 | 1:200 / 1:600 / 1:3000；暂停只停潮汐钟，浪照常拍岸 |
| 潮汐表 | 当天的潮位曲线叠在日照色带上，标出高低潮时刻与潮高；拖动或方向键改变时间 |
| 手写 / 写字 | 在沙上拖动留下划痕，或输入文字再点沙滩；书写时镜头停住，读数与潮汐表收起 |
| 抹平 | 清除所有痕迹 |
| 镜头 | 沿岸漫步（自动）、蹲在水边（固定）、自己看（拖拽与缩放） |

界面沿用《星轨》的边注式语言：竖排标识、写在画面边缘的读数、圆形按钮、按数据着色的时间轴。色调随太阳高度在「纸色墨字」与「底片黑银白字」之间切换，带回差并做 1.2 秒过渡，避免黄昏时墨色与底色一起落到中灰。

## 核心机制

1. **天文谐波潮汐**：`h(t) = Z0 + Σ Aᵢ·cos(Vᵢ − gᵢ)`，天文相角用 Doodson 平均经度构造。M2 = 2τ、S2 = 2T，两者相位差恰好是「2 × 月相角」，所以大小潮的 14.77 天拍频由频率自然产生，不是贴上去的装饰。河口加了 M4 浅水分潮，涨潮 5.6 小时、落潮 6.5 小时。
2. **程序化海岸**：`scene/terrain.ts` 用 tanh 衔接的剖面加噪声生成三种地形——沙丘、滩肩、滩面、槽沟与沙坝；盐沼、宽缓泥滩与蜿蜒潮沟；岩坡、小沙滩、浪蚀平台、巨石与潮池。CPU 保留全精度高度用于镜头取点和书写求交。
3. **上冲与水面**：涌浪不做时间压缩；近岸叠加一层上冲水膜，快速涌上、缓慢回落，波峰沿岸错开。沙面、水面与湿度场共用同一段 GLSL，看见的水和变湿的沙永远一致。
4. **湿度 / 痕迹 / 泡沫场**：一对半浮点乒乓渲染目标，规则写在 `tide/lifecycle.ts`：被水覆盖时湿度置 1、痕迹按 0.3 小时衰减；露出后湿度按 1.1 小时变干，痕迹只被风极慢地抹平；退水处留下一道泡沫花边。打开页面、换海岸或跳转时间后会先回放三小时，湿沙带一开始就在该在的位置。
5. **日月光照**：太阳与月亮的地平坐标决定光色、影子方向、天空渐变、星空与月相圆盘；月光强度随月面照亮比例变化。
6. **程序化音景**：涌浪的「沙——」、回落的砾石声、底层低频涌声、泡沫破裂的细碎声，全部由噪声与滤波器合成，按镜头前那段岸线的涌浪相位触发。

## 模块说明

| 模块 | 职责 |
| --- | --- |
| `src/tide/model.ts` | 分潮定义、天文相角、潮位与变化率、高低潮搜索、月相 |
| `src/tide/lifecycle.ts` | 湿度与痕迹的衰减规则（着色器与验收共用） |
| `src/tide/day.ts` | 当地一天的潮位曲线、高低潮与日照色带；海图基准面 |
| `src/astro/sky.ts` | 日月低精度位置、场景方向换算、时区 |
| `src/data/coasts.ts` | 三种海岸的分潮振幅、涌浪、水色与参照地 |
| `src/scene/TideEngine.ts` | 引擎：时钟、光照、渲染、场推进、镜头、音景、书写输入 |
| `src/scene/terrain.ts` | 程序化地形与射线求交 |
| `src/scene/Fields.ts` | 湿度 / 痕迹 / 泡沫场、笔触与文字写入、预热回放 |
| `src/scene/shaders.ts` | 沙面、水面、天空、场更新、笔触与后期着色器 |
| `src/scene/palette.ts` | 按太阳高度插值的天空与光照 |
| `src/scene/Director.ts` | 三种镜头模式 |
| `src/audio/Surf.ts` | 程序化海浪音景 |
| `src/ui/*` | 海岸列表、潮汐表、水尺、竖排诗、设置抽屉 |

## 构建与验收

```sh
pnpm typecheck      # 严格类型检查
pnpm verify:tide    # 纯 Node：M2 周期、大小潮潮差比、朔望相位、湿度与痕迹生命周期、预算、与零依赖版的模型对账
pnpm verify:simple  # 零依赖版的真实浏览器验收（自带临时服务器，不需要先启动 dev）
pnpm build          # 生产打包

# 视觉验收需要先启动 pnpm dev 或 pnpm preview
TIDE_URL=http://127.0.0.1:3000/ pnpm verify:visual   # 三种海岸 × 四个潮位阶段，外加「写字 → 涨潮 → 抹去」三帧
TIDE_URL=http://127.0.0.1:3000/ pnpm make:og         # 重新生成 public/og-tide.jpg
```

报告与截图写到 `artifacts/`（已忽略），零依赖版的在 `artifacts/simple/`。软件渲染（SwiftShader 等）会自动降到最低画质档，截图脚本在 macOS 上会请求 Metal。

## 与设计稿的差异

- **泡沫**：没有做粒子系统，改为着色器内的程序化泡沫（上冲前缘、沙坝碎浪）加场里的残留泡沫通道。
- **涌浪**：四个分量只做竖向起伏，没有水平位移；波峰线不随等深线弯曲。
- **湿度场范围**：高精度场覆盖镜头活动的 160 × 180 米，场外按与水位的关系近似。
