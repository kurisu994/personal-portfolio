# 苔痕 · PATINA（简易版）

单文件实现，零第三方依赖，不发起任何网络请求。用浏览器直接打开 `index.html` 即可运行。

```sh
open index.html
```

工程版（React + WebGL2 + Rsbuild）保存在相邻的 [`../patina-showcase/`](../patina-showcase/)。

## 这是什么

Gray-Scott 反应扩散在暖纸底色上缓慢生长：从彼此不相连的斑点起，一路长成密集圆斑、迷宫与细密分叉，最后几乎铺满整张纸；接着一圈水渍从中心洇开，把它洗回纸面，从头再来。

- **点一下** 播种，**拖动** 涂抹，**按住不动半秒**或**按住 Shift / 右键**擦除。
- **空格** 暂停。
- 一轮约四分钟。声音只有工程版有，这里刻意保持安静。

## 与工程版的差异

| | 简易版（本目录） | 工程版 |
| --- | --- | --- |
| 依赖 | 无 | React · TypeScript · WebGL2 |
| 渲染 | Canvas 2D + `ImageData` | WebGL2 双浮点纹理 ping-pong |
| 质点 | CPU `Float32Array`，每帧 8 步 | GPU，每帧 16 步 |
| 音景 | 无 | 程序化合成 |
| 墨晕与纸纹 | 与左邻差分 + 预计算纸纹 | 屏幕空间噪声与暗角 |

两个版本共用同一套扩散系数与形态族参数，模拟场都是固定 256²；差别只在「谁来算」和「怎么画」。实测两边长出的图案一致（同样种子下覆盖率 0.230 与 0.229）。

## 几个实现上的取舍

**用 `Float32Array` 而不是 8 位定点。** 定点看着够用，实测却会毁掉稀疏形态：V 的小值梯度被 `1/255` 的量化抹平，图案维持不住。256²、25000 步下与 `Float64` 参考对比：

| 形态 | Float64 参考 | Float32 | 8 位定点 |
| --- | --- | --- | --- |
| 斑点 | 0.233 | 0.232 | **0.015** |
| 细胞分裂 | 0.311 | 0.310 | **0.022** |
| 迷宫 | 0.424 | 0.422 | 0.450 |
| 珊瑚 | 0.529 | 0.524 | **0.025** |
| 茂密 | 0.966 | 0.962 | 0.802 |

只有迷宫恰好正常——第一次验证时只测了它，因此得出过「定点够用」的错误结论。

**形态顺序按覆盖率递增。** 不能改成「茂密 → 稀疏」：Gray-Scott 铺满之后 U 已耗尽，而反应项需要 `u·v²`，切到任何稀疏形态都会让画面变成一张白纸且再也长不回来。

**颜色查表。** 纸墨色阶在启动时预计算成三张 256 项查找表，渲染内层循环只做数组取值，不算插值。

**冲刷距离预计算。** 每个格子到画面中心的距离是定值，放在内层循环里每帧要多算五十万次开方。

## 调试接口

`window.__PATINA__` 暴露 `snapshot()` / `sow(n)` / `advanceToMorph(id)` / `restart()`，供工程版的 `verify:visual` 同时验收两个版本使用。页面自身的逻辑不读它。
