# 潮汐 · TIDELINE

创建：2026-09-17 ｜ 状态：待评审 ｜ 形态：双版本（零依赖单文件 / 工程化）

## 定位

一片潮间带，潮水按真实的谐波模型涨落，在沙上留下的痕迹被下一次涨潮抹去。

审美上这是与《候鸟》最亲近的一件：同样的纸与光，但介质从「前进的线」变成「来回的面」，节奏从旅程变成呼吸。

**记忆点**：可以在沙滩上写字画画，涨潮会把它擦掉。这个交互把「时间」变成可以亲手触碰的东西。

## 潮汐模型

谐波合成：

```
h(t) = Z0 + Σ Aᵢ·cos(ωᵢ·t − φᵢ)
```

分潮表（取主四项，足以产生大潮小潮与日不等现象）：

| 分潮 | 周期 (h) | 含义 |
| --- | --- | --- |
| M2 | 12.4206 | 主太阴半日 |
| S2 | 12.0000 | 主太阳半日 |
| N2 | 12.6583 | 太阴椭率（可选） |
| K1 | 23.9345 | 日月合成全日 |
| O1 | 25.8193 | 主太阴全日 |

**月相耦合**：S2 与 M2 的相位差取 `2 × 月相角`。朔望时两者同相叠加成大潮，上下弦时反相削减成小潮，拍频周期 14.77 天。这样「月相驱动」在物理上成立，而不是贴在画面上的装饰。

默认振幅（中纬度海岸）：

| 分潮 | 振幅 |
| --- | --- |
| M2 | 1.20 m |
| S2 | 0.35 m |
| K1 | 0.15 m |
| O1 | 0.12 m |

合计大潮潮差约 3.4 m，小潮约 1.9 m。

**站点预设**（振幅比不同，画面气质随之不同）：细沙滩（半日潮主导，如上）、河口泥滩（潮差大、涨落快）、内海（潮差小、水面平静）。

**时间压缩**：一个潮汐日（24h50m）≈ 150 秒（约 1:600）。档位：慢 1:200 / 中 1:600 / 快 1:3000（14.77 天大潮小潮周期约 7 分钟）。

**界面信息**：潮位曲线缩略图、当前潮位与涨落趋势、月相、太阳方位（决定光色与影子方向）。

## 地形

一维剖面 + 沿岸噪声：

- 剖面顺序：沙丘 → 干沙 → 滩面斜坡 → 沙坝 → 槽沟 → 潮池 / 礁石 → 浅水 → 深水，用 `tanh` 平滑连接，叠两层噪声。
- 沿岸方向：低频起伏 + 若干潮池凹坑，潮池在高潮淹没、低潮暴露。
- 三种海岸类型全部程序化生成，由种子决定。

## 水面与上冲

| 模块 | 做法 |
| --- | --- |
| 涌浪 | 3–5 个 Gerstner 波分量，波高与周期按离岸观测经验值 |
| 浅水变形 | 按水深压缩波长、抬高波高（近似 Green 定律），波峰线随等深线弯曲 |
| 上冲 | 每个涌浪按波高与水深入侵一段距离，泡沫线随之前进后退 |
| 泡沫 | 粒子 + 屏幕空间泡沫贴图；涌浪退去后泡沫残留并逐渐消散 |
| 湿润 | 标量场 `wet ∈ [0,1]`：涨潮置 1，退潮按干燥速率衰减；湿沙更暗、更光滑、反射更强 |

## 痕迹系统（核心机制）

一张与滩面同分辨率的「痕迹层」，记录沙纹、贝壳、脚印与用户涂鸦。

- 涨潮泡沫线经过时按 `wet` 衰减痕迹，用户写的字在一个半潮周期内被抹掉。
- 用户工具：手绘（拖动留下划痕）、文字（Canvas 文字 API 生成凹痕）、清除。
- 痕迹只在露出水面的沙上清晰可见；高潮时隔着浅水仍隐约可见，强化「被淹没」的感觉。

## 镜头

沿用《候鸟》导演系统的思路，三种模式：

| 模式 | 说明 |
| --- | --- |
| 自动 | 沿岸缓慢横移，周期性推向潮线；镜位变奏规则可复用《候鸟》的 Director |
| 固定 | 贴近沙面的静观，看清水线与泡沫的最佳视角 |
| 自由 | 拖拽环绕 + 滚轮 / 双指变焦 |

## 声音（三层，全程序化）

| 层 | 内容 |
| --- | --- |
| 涌浪 | 带通噪声 + 按波浪周期的一次包络（「沙——」），退去时加高频砾石摩擦 |
| 底层 | 40–120 Hz 低频涌声，厚度随潮位上升 |
| 细节 | 泡沫破裂的密集短包络（高频噪声，随机触发并限流） |

无需任何音频素材，全部由噪声与滤波器合成。

## 诗

10–12 段中英对照。主题：来与回、抹去与留下、写在沙上的东西。

## 双版本

| 版本 | 形态 | 保留什么 |
| --- | --- | --- |
| 零依赖版 `tide/` | Canvas 2D 侧视剖面：滩面剖面线、水位线、泡沫线、月相弧、潮汐曲线 | 完整的潮汐算法 + 「写字被抹去」的核心交互 |
| 工程版 `tide-showcase/` | Three.js 全 3D | 浅水、湿沙、泡沫、镜头与音景的全部表现力 |

2D 版的克制反而贴合「静观」，且它与 3D 版共用同一份潮汐模型定义与测试向量。

## 验收

`pnpm verify:tide`（纯 Node）

- M2 周期：30 天模拟内相邻波峰间隔误差 < 0.01 h。
- 大潮 / 小潮潮差比落在 1.6–1.9（由四项分潮振幅决定的理论区间）。
- 相位关系：朔望时刻潮差最大、上下弦最小。
- `wet` 场：涨潮阶段单调不减，退潮衰减到 0。
- 痕迹生命周期：写入后在一个半潮周期内被清除。
- 预算：泡沫粒子上限、同屏涌浪数上限。

`pnpm verify:visual`：三种海岸 × 四个潮位阶段（低潮初、涨半、高潮、退半）截图；以及「写字 → 涨潮 → 抹去」三帧序列。

## 风险

- 浅水的真实感依赖 shader 功底；湿沙与水下沙的材质过渡最容易出破绽。
- 性能压力来自高度场分辨率 × 波浪分量数 × 泡沫粒子，需要在移动端实测并设预算。
- 2D 与 3D 两版必须共用潮汐模型，否则「同源」这个卖点不成立。
