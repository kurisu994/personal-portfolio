# 一木 · ARBOR

## 已确认的方向

《树之物语 · SHUZHI》更名为《一木 · ARBOR》。“一木”取自「因缘归一木，天地此心宽」，由种子、枝叶、果实与归鸟组成一个小世界。

- `arbor/index.html` 保留原零依赖实现，仅调整品牌、阶段名和诗句；原 `shuzhi/` 路径更名为 `arbor/`。
- `arbor-showcase/` 是独立工程版，沿用其他 showcase 的 TypeScript、React、Rsbuild 与 pnpm，不要求单文件。
- Three.js、GSAP（ScrollTrigger / EasePack）、SimplexNoise 由 pnpm 固定并打包，不使用运行时 CDN。
- 用户已授权重写禅意文案。保留自然意象与清楚的操作说明，不将原创诗句冒称古诗。
- 最新交互调整：两个版本都取消鼠标引起的树体形变；仅保留时间驱动的自然风。工程版按住拖拽只调整镜头。

## 实施顺序与边界

1. 重命名原版，保留原有渲染与生长；按用户追加要求改写文案并移除鼠标风力、悬停视差。
2. 建立工程与依赖；公共数学、四阶 Bézier 气候插值先行。
3. 并行实现树体材质、React 叙事界面、Boids 与 WebAudio；主引擎整合时间轴、镜头、纸张后处理和输入。
4. 类型检查和生产构建；模拟检查生命周期、反向滚动与着陆。
5. 真实浏览器逐阶段检查桌面、手机和横屏；依据截图修改渲染及构图问题。
6. 交付运行说明、依赖许可与验证记录。根聚合页、Docker 和部署脚本不在本轮修改范围。

## 架构约束

原生有效滚动距离为 10000px，文档总高度是该距离加当前视口高度。五章各对应2000px。唯一 GSAP 时间轴给出绝对进度，几何随进度求值，不依赖单向触发事件。根0–.2、干.16–.5、侧枝.5–.7、末枝与叶.7–.9、果.85–.92、鸟.92–1。

分形树使用连续主干 TubeGeometry、噪声路径和沿弧长调径，合并木质几何并通过深度预通道避免树叉重复积墨。叶片实例化。树、果、巢和栖鸟共用世界空间形变函数，禁止各段独立旋转导致断裂。固定42颗果实、5只纸鸟和300粒子。

自定义水彩 Shader 包含三维颜料噪声、暗边、水渍、实际光照参数与雾；MultiplyBlending 采用符合当前 Three.js 版本的预乘设置。渲染流程为 RenderPass → OutputPass → FXAA → 纸张 Shader；纸纹本地生成并由 DataURL 装入，无外部图片。

React 不持有高频模拟数据，引擎仅低频回传界面快照。严格模式重挂载必须清理 RAF、监听器、GSAP、AudioContext 和 GPU。声音由显式用户手势启动，音频失败不阻止视觉。

镜头根据生长范围和 DOM 文字安全区取景。桌面左诗右树、手机上景下诗、短横屏左右布局；触屏保留 pan-y。拖拽观察停手2秒后弹簧归位。支持DPR上限、持续慢帧降级、后台暂停和减少动态效果。

## 验收

- `pnpm typecheck`、`pnpm build`、聚焦的 `pnpm verify:simulation`。
- 气候端点与连续性、拓扑有限值、挂点时序、反向隐藏、终点五鸟落地。
- 真实页面无shader/console错误；按钮、焦点、音频、全屏、滚动、观察回正。
- 1440×900、390×844、320×568、667×375及大屏，五章图文不相压、根干冠不意外裁切。
- 构建产物可静态部署到 `/arbor-showcase/`；字体和脚本资源正确加载。
- 不把本机短时帧率或模拟设备截图等同于所有真机性能保证。
