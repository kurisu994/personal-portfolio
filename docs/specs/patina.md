# 苔痕 · PATINA

创建：2026-09-17 ｜ 状态：待评审 ｜ 形态：双版本（零依赖单文件 / 工程化）

## 定位

暖纸底色上，几点种子缓慢长出苔绿与墨色的纹理；长满整幅后换一种形态继续生长。屏幕上的生长，也是全套里算法最简的一件。

## 体验设计

一轮完整生长分三幕，循环进行，耗时 3–5 分钟：

| 幕 | 内容 |
| --- | --- |
| 种子 | 随机 3–8 个注入点，随即开始扩散 |
| 蔓延 | 扩散前沿清晰可见，形态随参数族缓慢变化 |
| 饱和 | 覆盖率超过 85% 后进入参数漂移，纹理从珊瑚转为迷宫或斑点 |
| 重生 | 覆盖率超过 96% 或到达时长上限，用一次「水渍冲刷」转场回到种子幕 |

转场的视觉是湿纸被洇开：V 场被一个径向噪声衰减掉，而不是硬切。

## 算法

Gray-Scott 方程组，两个标量场 U、V：

```
U' = U + (Du·∇²U − U·V² + F·(1−U))·dt
V' = V + (Dv·∇²V + U·V² − (F+k)·V)·dt
```

- 扩散系数取经典稳定组合：`Du = 0.2097`、`Dv = 0.105`、`dt = 1.0`。
- 拉普拉斯用 9 点加权核。
- 边界用环绕（wrap），便于把苔面当作无限平铺的织物；若需要「容器感」再改钳制（clamp）。
- 演化速度靠**增加每帧步数**（而不是放大 dt），dt 一经调大就会发散。

形态参数族（Pearson 分类，取 5 组）：

| 名称 | F | k | 形态 |
| --- | --- | --- | --- |
| 珊瑚 | 0.0545 | 0.062 | 分叉枝状 |
| 迷宫 | 0.029 | 0.057 | 蜿蜒条纹 |
| 斑点 | 0.030 | 0.062 | 孤立斑点 |
| 细胞分裂 | 0.0367 | 0.0649 | 不断分裂的球形 |
| 负片迷宫 | 0.018 | 0.051 | 底色成纹 |

**参数漫游**：导演系统在 (F, k) 平面上沿一条预设折线移动，每段停留 40–60 秒，切换时用 8 秒插值避免突变。折线必须绕开不稳定区（F 或 k 过小会退化为全空或全满）。

## 渲染

**工程版（`patina-showcase/`）**

- WebGL2 + 两张浮点 ping-pong 纹理（`RG16F`，需 `EXT_color_buffer_float`；不可用时退化到 `RGBA8` + 定点缩放）。
- 每帧 12–20 个模拟步。
- 模拟场 768² 或 1024²，显示时双线性放大到画布。
- 后处理：纸纹叠加（复用《候鸟》的程序化纸纤维思路）、V 的梯度做边缘墨晕、轻微暗角。

**零依赖版（`patina/`）**

- Canvas 2D + `ImageData` + 双缓冲 `Uint8Array`，模拟分辨率 288×180（约 5.2 万格）。
- 每帧 6–10 步；V 以 0–255 定点存储并整体放大 256 倍精度，避免浮点与量化停滞。
- 帧率不足时降采样到 224×140。
- 配色用预先算好的色调查找表，避免逐像素调色函数。

## 纸墨配色

| 用途 | 色值 |
| --- | --- |
| 纸底 | `#f6f2e9` |
| 苔绿 | `#6f7a5a` |
| 深苔 | `#46503a` |
| 墨 | `#3a362c` |
| 铜锈 | `#8a6f4a` |

V 通道映射色阶：低 V 为纸，高 V 为深苔与墨；中等 V 区间叠一层铜锈色，制造「旧物」的时间感。

## 交互

| 操作 | 行为 |
| --- | --- |
| 点击 / 触摸 | 播种（注入一小团 V） |
| 长按 / 右键 | 擦除 |
| 拖动 | 涂抹（写字、画线） |
| 数字键 1–5 | 直接切到某个形态族 |
| 滚轮 | 调节「代谢速率」（整体偏移 F 与 k，不改变形态族） |
| 空格 | 暂停 / 继续 |
| AUTO | 开关自动导演（默认开） |

## 声音

- 底层：随覆盖率上升而增厚的低频嗡鸣（两个 40–90 Hz 正弦 + 轻微失谐）。
- 事件音：新核形成时一声清脆点音，限流为每 400 ms 最多一次，音高在五声音阶内按核的位置选取。
- 转场：重生时一次低频「水声」（噪声 + 低通扫频）。
- 默认静音，首次交互后可开，顶部保留开关。

## 诗

8–12 段中英对照短诗。主题：缓慢、不被看见的生长、覆盖与重生。

## 验收

`pnpm verify:patina`（纯 Node，直接跑 CPU 版内核，无需浏览器）

- 五组参数各跑 5000 步：断言无 `NaN` / `Inf`，V 落在 `[0, 1]`。
- 播种后 200 步内 V 总量单调增长。
- 参数插值过程中 V 总量无跳变（相邻步变化 < 5%）。
- 连续 5 万步（等价约 20 分钟）无溢出。
- 覆盖率曲线写入 `artifacts/patina/`。

`pnpm verify:visual`（真实 Chrome）

- 五组参数各截一张；覆盖率增长曲线；288×180 与 1024² 两版构图的结构相似度超过阈值。
- 视口沿用《候鸟》四档（390×844 / 1440×900 / 2200×1240 / 3300×1856）。

## 风险与待确认

- **浮点纹理**：Safari 上 `EXT_color_buffer_float` 的可用性需实测；`RGBA8` 退化路径要验证不出现低位深棋盘伪影。
- **零依赖版精度**：`Uint8` 定点在 `dt = 1` 下可能导致量化停滞；实测不足则改 `Uint16`（每像素两字节）。
- **回退方案**：若零依赖版始终不够惊艳，改成「低分辨率 + 无限平铺」（wrap 边界 + CSS 平铺）形态，定位为「会生长的壁纸」。
