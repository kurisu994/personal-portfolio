# 星轨 · STAR TRAILS

创建：2026-09-17 ｜ 状态：待评审 ｜ 形态：双版本（零依赖单文件 / 工程化）

## 定位

输入地点与日期，用真实星表算出一夜的星轨。地平线上是剪影，星点沿同心圆弧划出轨迹，曝光过程可见，结果可以带走。

这是作品集里第一件**算得准**的作品：天文算法有权威参考值可对账，验收脚本能在没有浏览器的环境里独立证明正确性。

## 双版本为什么合理

两个版本不是重复劳动，而是各自回答一个不同的问题：

| 版本 | 绘制方式 | 擅长 | 取舍 |
| --- | --- | --- | --- |
| 零依赖版 `star-trails/` | 解析绘制圆弧 | 任意时长（一夜 / 一年 / 极昼极夜）、任意分辨率导出、精度可验证 | 没有「逐渐显影」的过程感 |
| 工程版 `star-trails-showcase/` | 累积曝光（加性混合） | 真实的逐渐显影过程、光晕与噪声质感 | 时长受重建成本限制 |

两版共用同一套测试向量，保证同源。

## 天文算法

| 模块 | 职责 | 依据 |
| --- | --- | --- |
| `astro/time.ts` | UTC ↔ 儒略日、格林尼治恒星时、地方恒星时 | Meeus 第 7、12 章 |
| `astro/precess.ts` | J2000 → 观测日期的赤道坐标 | Meeus 第 21 章（近似三转角） |
| `astro/horizontal.ts` | 赤道坐标 → 地平坐标（高度角 / 方位角） | Meeus 第 13 章 |
| `astro/refraction.ts` | 大气折射修正（低高度角抬升约 0.5°） | Saemundsson 公式 |
| `astro/sun.ts` | 太阳视位置、日落 / 日出 / 暮光时刻 | Meeus 第 25 章低精度 |
| `stars/catalog.ts` | 星表加载、B−V → RGB 色温 | 普朗克曲线近似 |

处理顺序：星表赤道坐标 → 岁差修正 → 时角 → 地平坐标 → 折射修正 → 投影。

## 星表（待确认，最高优先级）

需求字段：赤经、赤纬、视星等、B−V（或光谱型）。

| 候选 | 规模 | 许可状况 | 取舍 |
| --- | --- | --- | --- |
| BSC5（Yale 亮星表，ADC 目录） | 约 9110 颗 | 事实性数据 / 公有领域主张 | **建议**：裁剪到 `mag ≤ 4.5`（约 1600 颗），以 `Float32` 数组内嵌（约 26 KB） |
| HYG v3 | 约 12 万颗 | CC BY-SA（署名 + 同许可） | 会给 MIT 代码的许可叙述带来负担 |
| Gaia 子集 | 十亿级 | 非商业条款 | 风险高，不用 |

**落地前必须确认许可**，并在 README 声明来源与版本。裁剪脚本要入库（`scripts/build-catalog.mjs`），让筛选过程可复现。

## 投影与画面

- **主视图**：面向北（或南）天极的透视投影，视场角 30°–100° 可调；此时星轨是同心圆弧。
- **全天域模式**：立体投影（stereographic），整个天球压进画面，星轨成为完整同心圆。
- **前景剪影**：程序化生成树 / 山 / 屋轮廓，纯黑剪影，纸墨调性，由种子决定。
- 亮星更粗更亮；色温映射到暖白、淡蓝、橙红三档。
- 可选图层：银河带（星密度近似成的柔光带）、流星（随机，可关）。

## 时间与「一夜」

- 起止：日落（太阳高度 −0.833°）到日出；可切到天文暮光（−18°）到天文晨光。
- 时间压缩：默认 60 秒一夜，提供 15 / 60 / 180 秒档。
- 拖动时间：
  - 解析版直接重算，代价低；
  - 累积版需要重建曝光，提供「从头快进」与「跳到 t 的近似」两种策略，界面上标明是近似。

## 交互

- **地点**：内置约 40 个城市（含坐标与时区名）+ 手动输入经纬度 + 浏览器定位。
- **时区**：用 `Intl.DateTimeFormat` 求偏移，不引入时区库。
- **日期**：`<input type="date">`，支持 1900–2100（岁差近似在这个区间内够用）。
- **导出**：PNG（1× / 2× / 4×）。
- **分享**：URL 查询参数 `?lat=&lon=&date=&hours=&mode=` 可完整还原画面。这是本作品的主要传播路径。

## 声音

默认静音。可选夜风 + 稀疏虫鸣（程序化合成）。本作品的静默本身就是气质，不强行配乐。

## 诗

10 段中英对照。主题：一夜的耐心、靠近天极的「不动」、以及看起来不动其实在转的东西。

## 验收

`pnpm verify:astro`（纯 Node，无浏览器），输出 `artifacts/astro/report.json`：

| 检查项 | 参考值 | 阈值 |
| --- | --- | --- |
| 格林尼治恒星时 | Meeus 例 12.a：1987-04-10 19:21 UT → 8h34m57.0896s | 0.1 s |
| 太阳赤纬 | Meeus 例 25.a | 0.01° |
| 恒星地平坐标 | USNO / Stellarium 参考表（离线固化） | 0.05° |
| 岁差 J2000 → 2050 | Meeus 例 21.b | 0.01° |
| 日出日落 | NOAA 计算器（若干城市若干日期，离线固化） | 60 s |

参考值一律**离线固化进仓库**，不依赖运行时联网，否则验收会随外部服务漂移。

`pnpm verify:visual`：五个地点（北京、曾母暗沙、悉尼、雷克雅未克、南极点附近）× 三个日期截图。

## 风险

- **星表许可**：本项目唯一可能阻塞落地的外部依赖。
- **边界场景**：极昼极夜、南半球、赤道（星轨近乎平直）三类画面的崩溃风险，必须进验收用例。
- **内置城市表**：坐标与时区的准确性需要人工核对，宁可少而准。
