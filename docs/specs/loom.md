# 织机 · LOOM

创建：2026-09-17 ｜ 状态：待评审 ｜ 形态：仅工程版

## 定位

一台会织布的织机。程序化生成的图案一寸一寸织出来，织机的声音就是它的节拍。

织机带给作品集一抹全新的颜色：靛蓝、茜草、槐黄、生丝白，同时是传统色。

## 这件作品不能只是「格子动画」

真实感来自三个地方，缺一个就散架：

1. **组织结构**决定纹理与光泽（平纹 / 斜纹 / 缎纹的视觉差异极大）；
2. **线股是圆柱**，各向异性高光沿轴向拉伸，浮长越长越顺滑；
3. **织机的四拍动作**与声音严格同步，形成 ASMR 般的节奏。

## 织造与组织结构

| 结构 | 提综规律 | 视觉 | 手感 |
| --- | --- | --- | --- |
| 平纹 | 经线分两组交替（1/1） | 细密方格 | 结实朴素 |
| 斜纹 | 每纬错位一根（2/2） | 对角线纹理 | 柔软有坠感 |
| 缎纹 | 浮长 4–5 根（5/1） | 光滑少纹 | 有光泽 |

数据模型：`N_shaft × N_pick` 的 0/1 提综矩阵。最终图案由「提综序列 × 纬色序列」共同决定。

## 图案生成器

- **基元**：条带、回纹、菱格、连珠、阶梯。
- **操作**：重复、镜像、错位、跳色、缩放。
- 种子 → 提综序列 + 纬色序列，完全可复现。
- 目标是程序化近似中国织锦的常见结构，而不是随机花纹。**必须有语法约束**，否则会滑向噪声。

传统色卡：

| 名称 | 色值 |
| --- | --- |
| 靛蓝 | `#2b4b6f` |
| 茜草 | `#a8323c` |
| 槐黄 | `#c9a227` |
| 生丝 | `#efe6d3` |
| 墨 | `#3a362c` |

## 布料渲染

- 布面按格划分，每格依 warp face / weft face 决定颜色与法线。
- 线股光泽用沿轴向拉伸的各向异性高光。
- 细节：织口阴影、经线张力导致的轻微弧垂、纤维毛边的细碎噪声。
- 三种视角：正面俯视（看图案）、微斜侧视（看机械动作）、特写（看单根线）。

## 织造节奏与声音

四拍循环：**开口 → 投梭 → 打纬 → 换综**。

| 事件 | 视觉 | 声音合成 |
| --- | --- | --- |
| 开口 | 综片抬起，经线分层形成梭口 | 木质短促「咔」：带通噪声 + 快速衰减 + 两个共振峰 |
| 投梭 | 梭子穿过梭口，左右交替 | 「嗖」：噪声 + 带通扫频，声像随梭子位置移动 |
| 打纬 | 筘把纬线推到织口 | 「啪」：低频冲击 + 木质共振，四拍中最重 |
| 换综 | 切换纬色或提综 | 线的摩擦细响（高频噪声，短） |

视觉与声音由**同一个事件总线**触发，因此「对齐」是可断言的，不靠肉眼。

节奏档：40 / 70 / 120 BPM（从手作慢速到机械中速）。

## 织造与循环

- 幅宽 240 根经线，每幅 300 纬。
- 织口线随纬数推进：已织部分是布，未织部分是张开的经线（能看到综片与间隙）。
- 织满后：剪下（布的边缘出现毛边）→ 布垂下或卷起 → 重新上经（新种子 / 图案 / 配色）→ 继续。
- 可导出成品 PNG（纹理级分辨率，可当壁纸）。

## 交互

| 操作 | 行为 |
| --- | --- |
| 自动模式（默认） | 织机自己跑，适合静静看 |
| 手动模式 | 空格 / 点击推进一纬，参与节奏；错拍不惩罚 |
| 切换 | 组织结构、配色卡、速度、视角 |
| 暂停 | 定格当前布面 |
| 导出 | 当前布面 PNG、提综矩阵 JSON（可复现） |

## 诗

8 段中英对照。主题：一寸一寸、重复里的手作、器物上的时间。

## 为什么不做零依赖版

单文件版会把线股光泽、织口阴影、机械动作全部压平，退化成「格子动画」，失去这件作品的立身之本。在 README 里写清这个取舍，比硬凑一个简版更诚实。

## 验收

`pnpm verify:weave`

- **结构断言**（从提综矩阵推导）：平纹相邻纬反相；斜纹每纬错位 N 根；缎纹浮长符合定义。
- **交织率**：经面 / 纬面格子比例符合结构定义。
- **可复现性**：同种子 → 提综矩阵哈希一致。
- **声音对齐**：织造事件时间戳与音频调度时间差 < 1 帧。
- **预算**：每帧绘制实例数上限；布面推进不跳纬。
- **视觉**：三种结构 × 三套配色 × 三个视角截图。

## 风险

- **真实感依赖对织机的理解**：落地前先做资料研究（传统木织机的开口—投梭—打纬动作、组织结构图样），并在 README 写明参考来源。这是本作品最大的时间成本。
- **程序化提花容易滑向随机噪声**：靠图案语法的约束解决。
- **渲染成本**：每根经线若独立几何会爆；必须实例化 + LOD。
