## 1. 目标与边界

新增独立的 `shuzhi-showcase/`，将树木的五段生命叙事实现为真正的 Three.js 水彩交互作品。沿用 `migration-showcase/` 与 `patina-showcase/` 的开发方式，不将现有 Canvas 实现简单包装为 React 组件。

用户最新要求取代最初的单文件交付要求：采用现代 TypeScript 工程，第三方依赖通过 pnpm 管理，构建为可静态部署的站点，不依赖运行时 CDN。

必须原样保留 `shuzhi/index.html`。实现前记录的 SHA-256 为：

不修改其他作品、不升级整个仓库的技术栈、不加入服务端、账号、外部模型或外部音频。根目录聚合作品入口、Docker 与部署脚本不在本轮修改范围；工程版提供独立构建和子目录部署说明。

## 2. 技术选择

- TypeScript 严格模式、React、Rsbuild，与两个现有 showcase 一致；不引入 Vite 或 React Three Fiber。
- `.node-version` 沿用 `lts-krypton`，包管理器沿用 `pnpm@12.4.2`。
- React、Rsbuild、TypeScript、Three.js 及类型声明沿用 `migration-showcase/package.json` 的版本系列；新增 GSAP 3.x（ScrollTrigger、EasePack）与 simplex-noise 4.x。实际解析版本由 pnpm 生成的 lockfile 固定，不手工编辑 lockfile。
- Three.js 核心与 EffectComposer 等 addons 均来自同一 `three` 包，杜绝跨版本 CDN 组合。
- Lucide React 图标；字体沿用工程版的 Noto Serif SC 与 Manrope 并打包自托管；界面不用 emoji。
- 引入依赖时检查许可证，将需要随分发保留的声明放入 `public/licenses/`；GSAP 按自身许可证处理，不宣称所有依赖都是 MIT。
- 脚本提供 `dev`、`typecheck`、`build`、`preview` 和聚焦生命周期的 `verify:simulation`。

## 3. 视觉与界面

延续《候鸟》的纸本留白、衬线中文与克制的英文标记、细线、缓慢镜头；主视觉是有体积的树，而不是高光塑料模型或发光粒子特效。

- 页面基底 `#F7F4EB`；场景中的土壤、天空、雾和光照覆盖其上，按生命阶段变化。
- 开场为暗啡土壤中的种子微距，暖白标题、暖金实色「落子生根 →」按钮。不得重新加入泛白的全屏蒙版；开始前隐藏并 inert 化旅程控制层。
- 桌面为左侧诗句、右侧主景，手机竖屏为上景下诗；不照搬《候鸟》的强制旋转横屏，因为本作品依赖原生纵向滚动。
- 短横屏单独布局；UI 缩放系数在 resize 中更新，触控按钮最小 44×44 CSS px。镜头取景使用扣除 UI 后的安全区。
- 声音、诗句、全屏控制与阶段标记保持轻量，不增加设置面板。全屏只由显式按钮触发，不强制占用屏幕。
- 五首诗逐字淡入，横线展开；按完整句子排版，避免标点落在行首。文本依所在区域亮度选用深墨或暖白，逐字动画可被阶段切换安全取消。


数据流：原生滚动 → ScrollTrigger / GSAP timeline → 生命周期数值 → 树、镜头、气候、终章。指针 → 风速滤波与观察偏移 → 场景形变和镜头。动画引擎直接维护高频数据，低频快照供 React 更新阶段、按钮和提示，禁止每帧重渲染整个 React 树。

`ShuzhiEngine` 对外仅提供开始、声音切换、销毁和只读状态快照；React 不持有或修改 Three.js 几何。全部模块具备明确资源所有权，StrictMode 重挂载不产生重复 RAF、监听器、AudioContext 或 ScrollTrigger。

## 5. 滚动生命线与气候

时间轴的有效滚动距离为 10000px，每段 2000px。为使最后一段也能完整滚到终点，文档总高度为 `10000px + 当前视口高度`；画布固定。这是对“10000px”按滚动距离的统一解释，避免把文档高度误当成可滚动距离。

ScrollTrigger 的开始和结束明确映射进度 0 与 1。生长状态由绝对时间轴求值，不能只依赖一次性进入事件；快速跳转、拖动滚动条与反向滚动都能恢复正确状态。滚动停下后，树的成熟程度不再继续增长，只有呼吸、风和粒子继续活动。

| 进度 | 生命变化 | 环境 |
| --- | --- | --- |
| 0–0.2 | 种子呼吸、根向下延伸，主干到达土面 | WARM：暗啡、温润淡黄 |
| 0.2–0.4 | 初芽、主干上升 | MIST：雾青绿、晨曦 |
| 0.4–0.6 | 主干拔高增粗，0.5 后一级枝伸出 | DUSK：橙粉、紫罗兰、逆光 |
| 0.6–0.8 | 二级与三级枝蔓延，0.7 后叶团展开 | FOREST：浓绿、翠蓝 |
| 0.8–1 | 树冠完成；0.85–0.92 结果；0.92–1 飞鸟归巢 | RECOMPENSE：暖金、天青 |

相邻气候在跨段窗口中连续混合，保留各段主体色。颜色、AmbientLight / DirectionalLight 的颜色与强度、FogExp2 密度与颜色、粒子样式共用同一气候采样，不各自跳变。

显式实现四阶 Bézier 标量函数：使用控制值 `[0, 0, 0.58, 1, 1]` 计算 Bernstein 基函数之和，即 `B(t) = 3.48t² − 2.96t³ + 0.48t⁴`。函数在 `[0, 1]` 单调，两端斜率为零；不将 `power4` easing 错称为四阶 Bézier。镜头路径独立使用连续空间轨迹，避免控制点切换的速度突变。

## 6. 树体与水彩

### 骨架和生长

用固定种子 PRNG 与 SimplexNoise 生成可复现的三维分形树，主干、根和各级枝均有父子关系、挂接位置、出生进度及生长区间。

TubeGeometry 沿弯曲路径生成，再沿弧长调整顶点半径，形成根粗梢细、轻微节瘤和手绘起伏。主干优先使用连续管线，侧枝在挂接处合理埋入父枝内部，不用球形接头遮缝。Tube 的可见长度与顶端半径随时间轴连续变化，避免 drawRange 截断留下粗平口。

子枝必须等待父枝到达挂接点；叶与果也等待所属枝段长到其位置。风形变采用共享的世界空间位移场，使枝、叶、果、巢与栖鸟的同一锚点得到一致位移，不给相邻枝段分别施加互不相关的旋转。

### 材质与纸张

- 树干、叶使用自定义 ShaderMaterial，三维噪声扰动颜料密度，轮廓暗边、局部湿边和纵向枯笔提供水彩层次。
- 使用 MultiplyBlending 表达颜料叠色；控制深度写入、背面与透明排序，避免连续主干接缝因反复叠色形成黑色圆环。重叠叶片允许自然积墨。
- 使用实际灯光数据和雾参数参与 Shader，不能只在 Scene 中摆放对自定义材质不起作用的灯光。
- Canvas 程序生成纸纤维与淡水渍，转为 DataURL 纹理。EffectComposer 在正确色彩空间下组合场景、纸纹与细噪点，避免重复 gamma 转换及全屏泛白。
- 叶片用共享几何与实例化批次降低 draw calls；滚动生长使用 `back.out(1.7)`，只产生短暂的尺寸回弹，不持续抖动。

## 7. 终章

- 生成 42 个 SphereGeometry 朱红果实（`#D9534F`），分布在已完成生长的二、三级枝末端；共享几何，0.85–0.92 从小水滴状回收为挂果，保持克制高光和细微风摆。
- 主树杈放置一只交叉线条组成的鸟巢；随终章显现，回滚时撤回。
- 五只纸鸟具备躯干、两翼和尾部。0.92 后从天际进入，Boids 使用分离、对齐、凝聚及有界转向；接近终点时增加栖息点吸引并淡出群集力。
- 停留在飞行区间时可盘旋；到达 1.0 必须在短暂收敛时间内落在树冠或鸟巢并停止振翅。反向越过终章时重置出生与着陆状态，重新前进可再次归巢；快速跳到终点不会遗留远处飞鸟。

## 8. 镜头、风与粒子

导演轨迹为：种子俯视微距 → 地表低角度 → 跟随主干上升 → 侧向环绕 → 全景揭示。最终镜位包含完整树冠、树根连接地表、果实和鸟巢，避免出现漂浮的截断树干。

滚动决定基础 `camera.position` 与 lookAt。原生 Pointer Events 拖拽叠加小幅 yaw/pitch，停手两秒后用带速度状态的阻尼弹簧回零。触屏保留纵向原生滚动，观察不抢占 `pan-y`；横向拖拽可用于微幅偏航，取消事件正确收尾。

指针速度经 1€ 滤波，再限制最大风力；世界空间扰动对根部近似为零，越高的枝叶越柔软。快速拖动不能导致树枝脱节或不可控抖动。

单个 Points 系统维护约 300 粒子，按阶段连续变换色彩、尺寸、速度与片元形状：尘絮、绿孢子、紫色光点、绿意飞絮、淡金花瓣。不能只换颜色而不改变运动和形态。

## 9. 声音、兼容与性能

声音只在开始或重新开启声音的用户操作中创建、resume。使用噪声缓冲、滤波器、包络和少量振荡器合成低风、叶响、终章鸟鸣；gain 平滑变化，避免点击杂音。声音失败不阻断视觉，按钮状态反映真实结果。

WebGL2 不可用、上下文丢失和音频不支持都有中文提示与适当的重试或静音路径；不显示永久加载遮罩。页面进入后台后暂停渲染与声音，返回时重置帧间隔，防止物理大步长跳变。

DPR 有上限并按持续帧耗时调整渲染比例；resize 同步 renderer、composer、相机、UI 与 ScrollTrigger，避免 canvas 清晰但后处理低分辨率。以桌面流畅 60fps 为目标，报告实测数据而非承诺所有设备性能。

处理 `prefers-reduced-motion`：关闭镜头漂移和强风响应，缩短文字动画，仍保留用户滚动控制的生命叙事。
